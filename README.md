# Runtrack 3 : JavaScript & Tailwind CSS

**Note** : Ce projet a été réalisé dans le cadre de ma formation de Développeur Web et Web Mobile (DWWM) au sein de La Plateforme.

Ce dépôt rassemble les exercices fondamentaux d'apprentissage de JavaScript, ainsi que l'intégration du framework CSS Tailwind. 

## Contenu du dépôt

- **jour01 à jour04** : Fondamentaux du langage JavaScript (algorithmique, manipulation du DOM, introduction à jQuery, requêtes asynchrones avec Fetch).
- **jour08** : Introduction et intégration du framework utilitaire **Tailwind CSS**. 

## Installation et utilisation

L'ensemble de ces exercices repose sur des technologies front-end (HTML, CSS, JS).
1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/geoffrey-carpentier/runtrack3.git
   ```
2. Ouvrez les différents fichiers d'entrée (`index.html` ou `index.php`) dans votre navigateur web pour visualiser les résultats ou tester les scripts.
